The system

One supervisor.
Six specialists.

RentACrowd runs synthetic studies with a LangGraph supervisor that dispatches six purpose-built agents — each owns a single job, reports back, and hands off. Nothing runs in a fixed pipeline; the supervisor reacts to what's actually needed.
